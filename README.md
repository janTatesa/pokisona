It is sadly pretty immature, though stuff like graph view and highlighting are planned

The core principles are:
1. **Minimalism** - intentionally few features
2. **Permanence** - once a idea is saved, it cannot be modified
3. **Atomicity** - the interface favors brief ideas

If you don't like it, pokisona is not for you
And also yea it uses a serif font
Note that the app currently assumes that the only way you will interact with the vault is by the app itself. This might change eventually
